# ThrillHikers Clone — Travel & Tour Company Web Platform

A production-ready travel & tour company web platform modeled directly after [ThrillHikers](https://thrillhikers.com). Built with Next.js 14 (App Router), TypeScript, and Tailwind CSS.

## Features
- **Hero & Interactive Filter Bar**: Search trips by destination, travel month, and group size.
- **Regional Destination Explorer**: Categorized grid (Himalayas, North East, International, Heritage, Beaches).
- **Upcoming Fixed Departures**: Live batch list with seats counter and solo-traveller booking callout.
- **Signature Bestseller Tours**: Detailed tour cards with review badges, pricing strikes, and duration.
- **Tour Detail Pages**: Dynamic routes with itineraries, inclusions, highlights, and instant enquiry trigger.
- **Modal Lead Capture**: High-converting lead generation modal connected to `/api/enquiry`.
- **Floating WhatsApp Engagement**: Direct WhatsApp click-to-chat trigger with pre-filled message.
- **Why Us & Traveller Reviews**: Trust-building statistics, captain highlights, and verified client testimonials.
- **FAQ Accordion**: Interactive questions covering payments, solo travel, and fitness requirements.

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## Deployment
Deploy seamlessly on **Vercel**:
1. Push this repository to GitHub or GitLab.
2. Import the project on [vercel.com](https://vercel.com).
3. Next.js will automatically detect the framework and deploy the site.
